## 页面特性

- **侧边栏目录**：分级导航 + 滚动位置自动高亮
- **折叠阅读**：点击标题即可展开/折叠内容，底部提供"全部展开/全部折叠"
- **考频标注**：★ 星级表示考频高低，题型徽章标明常见考法（单选/简答/辨析/材料分析/写作）
- **阅读进度条**：顶部实时显示阅读进度
- **响应式**：手机端自动切换为折叠式目录
- **打印友好**：打印时自动展开全部内容、隐藏辅助控件
